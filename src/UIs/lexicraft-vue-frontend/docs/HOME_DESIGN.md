# LexiCraft 首页设计说明

首页遵循前端根目录 `design.md` 的 Editorial 视觉系统。它不是蓝白渐变营销页，而是一张安静的学习入口：左侧给出学习主张，右侧展示一个真实的词汇学习片段。

## 结构

- 固定顶栏：品牌、页内导航、语言切换、登录和开始学习。
- 开场区：短 eyebrow、两行主标题、说明、主次按钮和“今日学习”示例卡。
- 学习方法：用编号列表说明从内容到练习的路径。
- 学习内容：用边线分隔的条目说明词汇、阅读和练习。
- 收束区：保留一个明确的开始学习动作。

## 视觉约束

- 背景、文字、边线和强调色使用 `src/assets/css/themes.scss` 的语义变量。
- 标题使用 Editorial 衬线字体，说明和控制使用无衬线字体。
- 不使用发光圆、蓝紫渐变、持续浮动、卡片放大和多重同权重 CTA。
- 移动端保持单列阅读顺序，主次按钮上下排列。

## 验证

首页的交互仍由 `src/pages/home.vue` 负责：语言切换、页内滚动、登录跳转和开始学习跳转保持不变。
