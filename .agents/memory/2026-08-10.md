# 2026-08-10 Identity OAuth 保存与前端动态导入修复

## 需求

- 修复 Identity OAuth 创建用户时数据库拒绝空 `password_hash` 的问题。
- 保留现有 `PasswordHash` 非空字段约束及迁移文件，不通过修改数据库结构规避保存逻辑缺陷。
- 消除前端 `src/utils/index.ts` 的 Vite 动态导入分析警告。

## 代码事实

- OAuth 登录在找不到本地用户时调用 `CreateUserCommand`，密码参数明确传入 `null`。
- `CreateUserCommandHandler` 原实现仅在密码非空时调用 `User.SetPassword`，因此 OAuth 新用户的 `PasswordHash` 保持为空，并在统一 `SaveChangesAsync` 时触发 PostgreSQL 23502 非空约束异常。
- Vite 的 `@vite-ignore` 注释原本放在 `import(url)` 上一行，不符合 Vite 要求的参数内注释位置，因此无法抑制分析警告。

## 实现变更

- `CreateUserCommandHandler` 在未提供本地密码时使用 `RandomNumberGenerator` 生成 32 字节随机值，再统一调用 `SetPassword` 写入 BCrypt 哈希；随机明文不持久化、不返回客户端，OAuth 用户仍没有可知的本地密码。
- 将动态导入调整为 `import(/* @vite-ignore */ url)`。
- 未修改、暂存或提交任何 Identity 迁移文件。

## 涉及文件

- `src/microservices/Identity/LexiCraft.Services.Identity/Users/Internal/Commands/CreateUserCommand.cs`
- `src/UIs/lexicraft-vue-frontend/src/utils/index.ts`

## 验证结果

- `dotnet build src\microservices\Identity\LexiCraft.Services.Identity.Api\LexiCraft.Services.Identity.Api.csproj --no-restore` 通过，0 个错误；保留既有 NuGet 多源映射警告。
- `dotnet build src\LexiCraft.slnx --no-restore` 通过，0 个错误；保留既有 NuGet 多源映射警告。
- `npm --prefix src\UIs\lexicraft-vue-frontend run build` 通过，原 `vite:import-analysis` 动态 URL 警告不再出现；仍有既有静态/动态重复导入和大分块提示。

# 2026-08-10 前端三套主题与首页登录页重设计

## 需求
- 为前端增加 A Warm Editorial、B Zen Focus、C Playful Ink 三套内部学习空间主题，并分别支持明亮、暗色和跟随系统模式。
- 首页和登录页固定使用 A 暖调书卷气视觉，不随内部 A/B/C 风格切换；登录页采用非传统的不对称编辑手稿布局。
- 加载界面、卡片、输入框、弹窗、按钮、布局导航等公共组件统一适配主题，保证文字与背景具备可读对比度。

## 代码事实与实现
- 新增 `src/UIs/lexicraft-vue-frontend/src/assets/css/themes.scss`，以语义化 CSS 变量集中定义 editorial、zen、ink 的明暗主题，并保留旧变量别名兼容既有页面。
- `setting` store 新增 `themeStyle`，默认 `editorial`；`theme.ts` 统一应用 `data-theme`、`data-theme-style` 和系统主题监听，避免覆盖其他根节点 class。
- 首页 `src/pages/home.vue` 改为固定 editorial 的阅读流式首页；登录页 `src/pages/(user)/login.vue` 改为固定 editorial 的非对称版式，同时保留账号、注册与 OAuth 入口。
- modern layout 增加三种内部导航形态：editorial 书签侧栏、zen 文本命令栏、ink 手绘浮动托盘；公共控件和设置页增加风格选择与明暗模式选择。
